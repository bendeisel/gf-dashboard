Invoke the `data-storytelling` skill (Skill tool) first (and `dataviz` if it's available) before building anything.

Turn the data described below into a story the audience can act on: lead with the one finding that matters, support it with the right chart, give context (vs last period, vs target), and end with what we'll do next. Use only real numbers from me — never fabricate, and label anything missing as "data pending". Plain, client-facing language. Deliver it in the format I ask for (HTML page, deck, or doc); if I didn't say, propose one. Start by restating the audience and the key message.
