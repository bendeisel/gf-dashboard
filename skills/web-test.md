Invoke the `webapp-testing` skill (Skill tool) first, then test what's described below.

Verify the real behaviour, not the code: open the page, perform the flow, capture a screenshot of the result, and collect console/network errors. Report what passed, what failed (with the exact error), and a screenshot path for anything visual. Never submit real forms that create leads, bookings, or payments on a live client site — use the test contact or a staging URL. Start by restating what you'll test and in what order.
