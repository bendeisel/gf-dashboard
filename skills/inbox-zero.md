Bring an inbox to zero by classifying mail and acting per category — safely, with the user in control of anything destructive.

## Steps
1. **Classify** each thread into clear buckets: **important** (clients, real people needing a reply), **notifications** (receipts, system), **promotions/marketing**, **cold email**, **group chats/newsletters**. Refine with a small knowledge base of known senders + a configurable rule set.
2. **Map each bucket to an action:** important → keep visible / flag for reply; notifications → mark read; promotions & cold email → label + archive; newsletters → label. Keep high-priority mail in view, never buried.
3. **Propose before acting.** Show the plan (counts per bucket + what will happen to each) and get a go-ahead before archiving or marking read in bulk. Start with a dry run on a small batch.
4. **Summarize** what was done and surface the short list of threads that actually need a human reply, with a one-line suggested response each.

## Rules
- **Never delete or send** without explicit approval — archive/label/mark-read only, and confirm the batch first. Trash is off-limits unless the user asks for it by name.
- Learn the user's real contacts so a client never lands in promotions. When unsure, leave it in "important" rather than hide it.
- Use the connected Gmail tools read-first; keep a clear audit of every action taken.
